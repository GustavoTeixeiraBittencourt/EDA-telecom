# Training and applying EDA concepts - Telecom Case

By Gustavo Teixeira 

Nesse projeto temos três conjuntos de dados com informações de clientes e serviços, incluindo uma variável que indica se o cliente abandonou a empresa (churn) ou não. O objetivo é utilizar esses dados e algumas hipóteses para obter insights iniciais e construir uma solução de inteligência artificial capaz de prever o abandono de clientes ativos. Para isso, vamos começar coletando e preparando os dados usando o Pandas. Vamos aprender a ler arquivos, transformar tipos de dados, renomear colunas e unificar os conjuntos de dados. 

## Objetivo

O principal objetivo deste projeto é consolidar meus conhecimentos em **exploração, tratamento e análise de dados**.

Para mim, que estou estudando a área de **Inteligência Artificial (IA), Machine Learning e LLMs**, compreender e trabalhar adequadamente os dados é uma das etapas fundamentais para o desenvolvimento de modelos e sistemas de IA capazes de apresentar resultados consistentes e coerentes.

Por isso, este projeto busca colocar em prática conceitos de **Exploratory Data Analysis (EDA)**, tratamento e preparação dos dados, visualização e análise de informações, criando uma base sólida para as etapas posteriores de desenvolvimento e avaliação de modelos de Machine Learning.
